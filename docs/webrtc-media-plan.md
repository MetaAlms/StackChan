## 原则

1. **每步都能独立止损。** 不把"发现不可行"推迟到最后一步。
2. **M1 不碰现有音频服务**（用预录 raw Opus），把音频改造推迟到 M1.5/M2。
3. **不删除任何现有实现**，只新增与切换。回退成本必须保持为零（SPEC §5.3）。
4. **每个里程碑结束都要有可复现的证据落盘**，不留在对话里。
5. **改动必须落在可重建位置**（SPEC §2.6）：`xiaozhi-esp32/` 与
   `managed_components/` 未被跟踪，不得只改那里。
6. **不自行宣告通过**：每个里程碑交 Codex 复核后放行。

## M1 — 上行通路

### 目标

用**预录 raw Opus**（不接麦克风）经 RTP 送至服务端，确认配置、发送、
VAD 与 ASR 四层各自可观测。

### 为什么用预录

- 完全不碰 `AudioService`、AFE、编解码队列
- 失败时能按 SPEC §6.1 的四层分类定位，而非混为一谈
- 与 SPEC §8 的"无转写不等于传输失败"要求一致

### 任务

| # | 任务 | 依据 |
|---|---|---|
| 1.1 | 初始化 **48 kHz 单声道** Opus 编码器；`get_frame_size` 与重采样输出对齐；**DTX 关闭** | SPEC §4.6 |
| 1.2 | 准备 fixture：**含前后静音**，尾部 ≥ `silence_duration_ms` + 余量；记录 hash/参数/预期关键词 | SPEC §6.1 |
| 1.3 | 16k→48k 重采样：**每声道样本数、容量查询、检查返回值、只用 `actual_out`、保留跨帧状态** | SPEC §4.6 |
| 1.4 | 在 M0 基础上加 `esp_peer_send_audio()`，**按媒体时间实时 pacing**；pts 按 §2.3 推进 | SPEC §2.3 |
| 1.5 | **单包 raw Opus 边界与容量校验**；超限丢弃并计数 | SPEC §2.4 |
| 1.6 | 等 `session.updated` 后发媒体；显式启用并**核对** `input_audio_transcription` 回显 | SPEC §6.1 |
| 1.7 | 四层日志：配置 / 发送（返回值、包数、字节、**媒体时长**）/ VAD / ASR（含 `transcription.failed`）| SPEC §6.1 |
| 1.8 | 先 20 ms 基线，再测 60 ms | SPEC §6.1 |
| 1.9 | **5 分钟资源检查** | SPEC §6.1 M1-3 |

### 退出条件

SPEC §6.1 的 M1-1 / M1-2 / M1-3。

### 明确不做

- 不接麦克风、不接 UI/表情、不碰 `AudioService`
- 不改 `OPUS_FRAME_DURATION_MS` 等全局常量（SPEC §4.6）

## M1.5 — AEC 假设验证（核心止损点）

### 目标

在投入产品接入之前，判定**服务端是否提供可用的回声控制**。

### 范围修正（P1）

评审指出：M1.5 **实际需要提前做原 M2 的一部分媒体接入**
（麦克风 + 服务端音频解码播放），**不能再称为"完全不投入双向链路"**。
它仍比完整产品移植小，但**不能从方法描述推定"工作量 1/3"**，
需按依赖重新估算。

**M1.5 只做媒体、事件与测量**，暂不接完整 UI/表情。

### 任务

| # | 任务 | 依据 |
|---|---|---|
| 1.5.1 | 下行：`on_audio_data` **回调内复制** → 有界非阻塞队列 → worker 解码 48k → 重采样 24k → 播放 | SPEC §4.4/§4.6 |
| 1.5.2 | **确认"播放时关闭采集/丢上行"逻辑不生效**（连续采集）| SPEC §4.5、§6.2 |
| 1.5.3 | 记录**实际播放 PCM 及时间**；不把"服务端生成完成"当"设备播放完成" | SPEC §6.2 |
| 1.5.4 | 执行 T1 正对照（喇叭关 + 近端人声）| SPEC §6.2 |
| 1.5.5 | 执行 T2 远端独说（≥30 s，多次，最高预期音量）| SPEC §6.2 |
| 1.5.6 | 执行 T3 双讲插话（旧播放是否**实际停止**）| SPEC §6.2 |
| 1.5.7 | 执行 T4 插话后再说话 | SPEC §6.2 |
| 1.5.8 | **内建实验有效性断言**：播放期间发送计数未按预期增长即判实验无效并中止 | SPEC §8 Q3 |
| 1.5.9 | 记录总排队时长、欠载/溢出、迟到率 | SPEC §4.7 |

### 退出条件（三类，不是二元）

| 判定 | 条件 | 动作 |
|---|---|---|
| **目标通过** | T1–T4 全通过 | 允许继续 M2；**不取代 M3** |
| **目标失败** | 实验有效前提下 T2 或 T3 不达标 | **交 Codex 评审后决策** |
| **实验无效** | T1 失败 / 媒体时间轴错误 / 播放时上行中断 | **先修实验**，不得据此判定 AEC |

### 明确禁止

- 不得用**半双工门控**掩盖目标失败
- 不得从"空转写"计算 ERLE 或给出 dB 抑制量
- 不得把 `speech_started` 当 AEC 指示器
