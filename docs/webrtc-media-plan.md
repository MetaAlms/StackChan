## 原则

1. **每步都能独立止损。** 不把"发现不可行"推迟到最后一步。
2. **M1 不碰现有音频服务**（用预录 raw Opus），把音频改造推迟到 M1.5/M2。
3. **不删除任何现有实现**，只新增与切换。回退成本必须保持为零（SPEC §5.3）。
4. **每个里程碑结束都要有可复现的证据落盘**，不留在对话里。
5. **改动必须落在可重建位置**（SPEC §2.6）：`xiaozhi-esp32/` 与
   `managed_components/` 未被跟踪，不得只改那里。
6. **不自行宣告通过**：每个里程碑交 Codex 复核后放行。
7. **测试先对时**：默认 Idle，显式 START/STOP；不因刷写/复位/进入探针而自动采集。
   一轮结束不自动启动下一轮；每轮先说明内容与时长，等待用户“开始”。

### 范围修正（P1）

评审指出两点：

1. M1.5 **实际需要提前做原 M2 的一部分媒体接入**（麦克风 + 服务端音频解码播放），
   **不能再称为"完全不投入双向链路"**，工作量需按依赖重新估算。
2. **更关键**：T3 已要求"旧播放实际停止"，而真实上行、本地停止、
   在途任务隔离与跨通道边界若仍排在 M2，
   **会把"探针未实现停止"误判成"目标失败"**。

因此下列能力**必须作为 M1.5 的前置完成并验证**，不得留到 M2。

| **实验无效** | T1 失败 / 媒体时间轴错误 / 播放时上行中断 / **M1.5 前置未完成** | **先修实验或补前置**，不得据此判定 AEC |

**"恢复缺陷"分支的判据**：若采集、时间轴或会话本身已失效，
按"实验无效"处理并先修实验；**不得把恢复缺陷直接归因为 AEC**。

### 明确禁止

- 不得用**半双工门控**掩盖目标失败
- 不得从"空转写"计算 ERLE 或给出 dB 抑制量
- 不得把 `speech_started` 当 AEC 指示器
- **不得在 M1.5 前置未完成时执行 T3/T4 并据其结果判定目标失败**
